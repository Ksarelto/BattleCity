# Controls

## Keyboard — Player 1

| Action | Key |
|--------|-----|
| Up | Arrow Up / W |
| Down | Arrow Down / S |
| Left | Arrow Left / A |
| Right | Arrow Right / D |
| Fire | Space / Z |
| Pause | Escape / P |

## Keyboard — Player 2

| Action | Key |
|--------|-----|
| Up | I |
| Down | K |
| Left | J |
| Right | L |
| Fire | Enter / H |

## Gamepad

- P1: Left stick / D-pad + A button (fire) + Start (pause)
- P2: Second controller same mapping

## Mobile Touch

- Left side: Virtual D-pad (8-direction disabled; 4-dir only)
- Right side: Fire button
- Optional: Pause button top-right

## Menu Navigation

| Action | Key |
|--------|-----|
| Navigate | Arrow keys |
| Select | Enter / Space |
| Back | Escape |

## Editor

| Action | Key |
|--------|-----|
| Paint tile | Click / tap |
| Erase | Right-click / long press |
| Cycle palette | Tab |
| Save | Ctrl+S |
| Play test | P |
