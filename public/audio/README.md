# Audio assets

## Game SFX (bundled)

Procedural WAV placeholders in this folder:

- `shoot.wav` — cannon fire
- `hit.wav` — shell impact
- `explosion.wav` — tank destruction
- `stage-start.wav` — round start jingle
- `engine.wav` — looping engine rumble

## Menu music (Helldivers 2)

The Helldivers 2 soundtrack is copyrighted and **cannot be redistributed** with this project.

To use it on the home screen:

1. Copy a track you legally own (e.g. from your purchase / OST) to:

   `public/audio/menu.mp3`

2. Refresh the app. The menu prefers `menu.mp3`, then `menu.ogg`, then `menu-fallback.wav`.

Menu music stops automatically when you enter `/game`.
